# Release Notes - v0.0.1

**Date**: May 20, 2026

Initial public release of the `dotfiles.cmarks` repository.

## Overview

This release establishes the foundational dotfiles configuration for a productive development environment targeting WSL (Windows Subsystem for Linux), with compatibility for native Linux and macOS.

## Key Components

- **Bash Configuration**:
  - `bashrc`: Sources custom aliases and functions, sets up a git-aware, color-coded prompt.
  - `bash_aliases`: Productivity aliases for navigation (`..`, `.2` etc.), colored `ls`/`grep`, history search, disk usage, Ruby/Bundler helpers, and tmux color fix.
  - `bash_functions`: Git status/branch functions for prompt coloring, `countFilesByExtension`, and legacy `cucumberStepStat` for BDD testing stats.

- **Vim Configuration**:
  - `vimrc`: Classic Vim setup using Pathogen for plugin management.
  - Colorscheme: `phix` (custom) with Solarized support.
  - Includes: vim-airline, CtrlP, Fugitive, Syntastic, SnipMate, and JavaScript-specific plugins.
  - Custom ctags configuration (`ctags`) for enhanced JavaScript symbol tagging.
  - `encrypted_vimrc`: Minimal secure Vim settings (no backups, swaps, or write backups) for editing sensitive files.

- **Tmux**: Minimal `tmux.conf` enabling mouse support.

- **Other**:
  - `conkyrc`: Configuration for the Conky system monitor.
  - `install.sh`: Automated symlink installer with backup support and git config setup.
  - `vim/bundle/`: Collection of Vim plugins managed as git submodules.
