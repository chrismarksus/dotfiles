# v0.1.0 - Modernization & Documentation Overhaul

**Date**: May 2026  
**Version**: v0.1.0

## Overview

This release represents a major modernization and documentation effort for the dotfiles repository. The project was significantly updated to reflect current development practices while preserving backward compatibility with the original 2010-era setup.

## Major Highlights

### Neovim Modernization
- Introduced a complete modern Neovim configuration located in `nvim/`
- Switched from Pathogen to `lazy.nvim` as the plugin manager
- Added essential modern plugins:
  - **Treesitter** for improved syntax highlighting and parsing
  - **LSP** support via Mason + nvim-lspconfig (Lua, Python, TypeScript, PHP)
  - **UI enhancements**: Tokyo Night theme, lualine, bufferline
  - **Productivity tools**: Telescope, gitsigns, Comment.nvim, which-key, nvim-tree

### Infrastructure & Tooling
- Fixed and improved `install.sh` (corrected filenames, added missing symlinks for bash aliases/functions)
- Added Docker-based testing infrastructure:
  - `Dockerfile` for reproducible testing environments
  - `test.sh` convenience script
  - `scripts/validate-install.sh` for validation checks
- Isolated legacy Ruby/Cucumber-specific code (`cucumberStepStat`) as reference only

### Documentation Improvements
- Complete rewrite of `README.md` with clearer structure
- Added Quick Start section
- Added "Release Notes & Versioning" section
- Added WSL / cross-platform usage notes
- Created semantic versioning release notes in `release-notes/`

### Release Process
- Established semantic versioning for release notes
- Created dedicated release branches:
  - `release/v0.0.1` (initial state)
  - `release/v0.1.0` (modernization)
- Added annotated tags `v0.0.1` and `v0.1.0`

## Key Decisions

- Neovim is now the recommended primary editor
- Classic Vim + Pathogen setup preserved for backward compatibility
- Docker testing added for safer future development
- Release notes are versioned and stored locally (not tracked in git)

## Impact

This release transforms the repository from a legacy 2010s Vim-focused setup into a modern, well-documented, and maintainable development environment. The project now serves both as a practical daily driver and as a learning resource.
