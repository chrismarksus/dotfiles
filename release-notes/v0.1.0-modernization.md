# v0.1.0 - Modernization Session

**Date**: May 2026  
**Version**: v0.1.0

## Summary

Major cleanup, modernization, and documentation effort. This release introduces Neovim as the primary editor while preserving backward compatibility with the classic Vim setup.

## Major Changes

### Neovim Modernization
- Created complete modern Neovim configuration in `nvim/`
- Switched to `lazy.nvim` as the plugin manager
- Added core plugins:
  - Treesitter
  - LSP support via Mason + nvim-lspconfig
  - UI improvements: lualine, bufferline, Tokyo Night theme
  - Productivity tools: Telescope, gitsigns, Comment.nvim, which-key, nvim-tree

### Cleanup & Maintenance
- Fixed `install.sh` (typos, correct filenames, added missing symlinks)
- Isolated Ruby/Cucumber-specific code (`cucumberStepStat`) as legacy
- Added Docker-based testing infrastructure (`Dockerfile`, `test.sh`, validation script)

### Documentation
- Comprehensive rewrite of `README.md`
- Added Quick Start section
- Clarified Neovim vs classic Vim relationship
- Added WSL / cross-platform notes
- Created release notes using semantic versioning

## Key Decisions

- Neovim as the recommended daily driver
- Legacy Vim setup preserved for compatibility
- Docker testing added for safer future development
- Session work documented for presentation and knowledge sharing

## Impact

This release transforms the repository from a 2010-era Vim-focused setup into a modern, maintainable, and well-documented development environment while respecting its history.
